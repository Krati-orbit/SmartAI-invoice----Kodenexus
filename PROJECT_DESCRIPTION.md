# Project Description: SmartInvoice AI

**Short Pitch (150 words):**
SmartInvoice AI is an intelligent invoice automation tool engineered to transform messy, unstructured customer requests—such as emails, Slack chats, and requirement briefs—into structured, priced, and review-ready professional invoices within milliseconds. 

Unlike conventional AI tools that hallucinate rates, SmartInvoice features a strict **Anti-Hallucination Pricing Engine** backed by an authoritative benchmark catalog of 15 services. Line items are accurately matched against official rates, while unrecognized custom requests trigger **Smart Fallback Alerts** for operator review. 

The application provides a responsive **Human-in-the-Loop review workspace** where users can adjust quantities, tweak unit prices, configure multi-tier GST/tax brackets, switch currencies, and export crisp, pixel-perfect PDF invoices in one click. Built with Next.js 16, Tailwind CSS, TypeScript, and multi-model AI support (Google Gemini, Groq Llama 3, and an offline NLP engine), it ensures zero-latency, error-free invoice generation every time.

**Key Highlights:**
- **Zero-Hallucination Guarantee:** 100% catalog-verified pricing for standard tech and design services.
- **Human-in-the-Loop:** Complete editorial control over client data, line items, taxes, and payment terms.
- **Smart Fallback:** Immediate amber flagging for bespoke/unrecognized services with inline remapping.
- **Multi-Model & Resilient:** Supports Gemini 1.5, Groq Llama 3, and operates seamlessly offline without API keys.
- **Production-Ready PDF:** Instant client-side A4 PDF export with high-DPI rasterization.
